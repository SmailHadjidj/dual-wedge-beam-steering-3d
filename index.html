LiDAR — Dual Rotating Wedges

Interactive 3D educational simulation · mouse drag = orbit · wheel = zoom · right drag = pan
Laser → Wedge 1 → Wedge 2 → Target plane
Wedge 1 speed ω₁ 1.00 Hz
Wedge 2 speed ω₂ -1.00 Hz
Relative phase φ 0°
The circular optical elements are wedge prisms: one face is tilted.

The displayed beam deflection is a simplified vector model intended to visualize how two rotating wedges combine.
